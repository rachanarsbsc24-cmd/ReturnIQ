# ReturnIQ — E-commerce Return Intelligence Platform

ReturnIQ is a e-commerce return analysis platform designed to help businesses record, organize, and understand product returns.

The application identifies common return reasons and highlights products that have frequent return issues, helping businesses make better decisions about product quality, sizing, descriptions, and customer satisfaction.

## Features

- Dashboard showing return statistics
- Record new product returns using a form
- Categorize returns by reason
- View all recorded returns in a table
- Analyze common return reasons
- Identify products with frequent returns
- Responsive and user-friendly interface
- Uses React components and state management
- Uses local mock data without a backend or database

## Project Structure

The main React files are kept inside the client folder.

- components contains the reusable UI parts such as the navbar, cards, form, table and analytics sections.
- pages contains the main dashboard screen.
- data contains the sample return records used in the project.
- App.jsx handles the main application flow and state.
- main.jsx is the entry point of the React application.
- index.css contains the overall styling.
- index.html is the main HTML file used by Vite.
